# دليل نشر المرحلة الثانية — لوحة المعلم ومزامنة تقدم الطلاب

> الهدف: ربط موقع HSK1 بجدول Google Sheets عبر Google Apps Script، بحيث:
> - يسجّل كل طالب دخوله بـ**اسمه + رمز دخول** يصدره المعلم، فتُحفظ تقدمه في الجدول.
> - يفتح المعلم **لوحة متابعة** (نفس رابط النشر) ويرى تقدم كل طالب وكل درس.
>
> كل الكود جاهز في مجلد `apps-script/` — دورك نسخ/لصق وضبط إعدادات فقط.
> المدة التقديرية: **15–25 دقيقة** لأول مرة.

---

## الملفات التي ستنسخها

| الملف في المشروع | إلى أين يذهب |
|---|---|
| `apps-script/Code.gs` | ملف السكربت الرئيسي `Code.gs` |
| `apps-script/LessonsData.gs` | ملف سكربت جديد باسم `LessonsData` |
| `apps-script/Dashboard.html` | ملف HTML جديد باسم `Dashboard` |
| `apps-script/appsscript.json` | (اختياري) ملف البيان في محرر السكربت |

> `LessonsData.gs` مولَّد تلقائياً من محتوى الدروس عبر `npm run lessons:export`.
> إذا تغيّر محتوى الدروس مستقبلاً: أعد تشغيل الأمر ثم حدّث الملف في Apps Script
> وأعد النشر (نسخة جديدة).

---

## الخطوة 1 — إنشاء جدول Google

1. افتح [sheets.google.com](https://sheets.new) وأنشئ جدولاً جديداً.
2. سمّه مثلاً: **HSK1 — تقدم الطلاب**.
3. لا تضف أي بيانات يدوياً — السكربت سينشئ الجداول السبعة تلقائياً:
   `Students` و`Lessons` و`StudentLessonProgress` و`StudentVocabularyProgress`
   و`LearningEvents` و`StudentQuizStats` و`Sessions`.

## الخطوة 2 — فتح محرر Apps Script

1. من داخل الجدول: القائمة **Extensions ← Apps Script**
   (بالعربية: الإضافات ← Apps Script).
2. ستفتح صفحة المحرر وفيها ملف `Code.gs` فارغ (أو فيه سطر واحد).

## الخطوة 3 — لصق الملفات الثلاثة

1. **Code.gs**: احذف محتواه بالكامل والصق محتوى `apps-script/Code.gs` من المشروع، ثم احفظ (💾).
2. اضغط **+** بجانب "Scripts" ← اختر **Script** ← سمّه بالضبط `LessonsData`
   ← الصق محتوى `apps-script/LessonsData.gs` ← احفظ.
3. اضغط **+** بجانب "Files" ← اختر **HTML** ← سمّه بالضبط `Dashboard`
   ← الصق محتوى `apps-script/Dashboard.html` ← احفظ.

> الأسماء مهمة: `Dashboard` يُستدعى بالاسم من `doGet`، و`LessonsData` يحمل ثابت
> `COURSE_DATA` الذي يستخدمه `Code.gs`.

## الخطوة 4 — رابط لوحة المعلم الخاص (بلا أي إدخال)

**لا يوجد رمز يدخله المعلم** — لوحتك تفتح مباشرة من **رابط خاص بك وحدك**:

1. شغّل الدالة `setupSheets` (الخطوة 5 أدناه) مرة واحدة.
2. افتح سجل التنفيذ (View ← Logs، أو Console أسفل المحرر ← Execution log)
   وستجد سطراً مثل:
   `TEACHER DASHBOARD LINK -> https://script.google.com/macros/s/AKfyc…/exec?k=Ab3xY9…`
3. **انسخ هذا الرابط واحفظه في المفضلة** — افتتاحه يعرض اللوحة فوراً دون أي
   سؤال. الرابط الأساسي (بدون `?k=`) يعرض صفحة فارغة "Nothing here" لكل
   من سواه — وهذا مهم لأن رابط الطلاب منشور داخل كود الموقع.
4. **إذا تسرب رابطك الخاص**: شغّل الدالة `rotateDashKey` من المحرر ← يولد
   مفتاحاً ورابطاً جديدين فوراً (الرابط القديم يموت) — دون إعادة نشر.
5. ملاحظة أمان إضافية: حتى لو وصل أحدهم للوحة، فعمليات المعلم محجوبة تقنياً
   عن واجهة الموقع العامة — لا يستطيع طالب استدعاءها من الموقع أبداً،
   والطالب لا يرى إلا بياناته هو (تحقيق في الخادم).

## الخطوة 5 — تشغيل الإنشاء الأولي (setupSheets)

1. عد إلى المحرر، واختر من القائمة المنسدلة للدوال: **setupSheets**.
2. اضغط **Run** (تشغيل).
3. أول مرة ستظهر نافذة صلاحيات:
   - **Review permissions** ← اختر حساب Google الخاص بك.
   - قد تظهر رسالة "Google hasn't verified this app":
     اضغط **Advanced** ← **Go to (project name) (unsafe)** — هذا طبيعي لأن
     السكربت من كتابتك أنت ويعمل على جدولك أنت.
   - **Allow** (سماح).
4. افتح الجدول: ستجد الجداول السبعة أُنشئت، وجدول `Lessons` معبأً
   بالـ15 درساً و331 كلمة (من محتوى الموقع نفسه).

## الخطوة 6 — النشر كتطبيق ويب

1. اضغط **Deploy ← New deployment**.
2. أيقونة الترس يسار "Select type" ← اختر **Web app**.
3. املأ:
   - **Description**: `HSK1 Phase 2`
   - **Execute as**: `Me` (حسابك أنت)
   - **Who has access**: `Anyone`
     (الرابط نفسه لا يمنح أي صلاحية — كل عملية تتطلب رمز طالب/معلم صالحاً)
4. **Deploy** ← انسخ رابط الويب app URL — ينتهي بـ `/exec`. مثال:
   `https://script.google.com/macros/s/AKfycb.../exec`

> **هذا الرابط الواحد يخدم الاثنين**: الطالب يستدعيه الموقع تلقائياً (POST)،
> والمعلم يفتحه في المتصفح مباشرة فتظهر له لوحة المتابعة (GET).

## الخطوة 7 — ربط الموقع بالرابط

1. في مشروع الموقع افتح `src/config.ts` وعدّل قسم `progress`:
   ```ts
   progress: {
     provider: 'remote',
     remoteEndpoint: 'https://script.google.com/macros/s/AKfycb.../exec',
   },
   ```
2. أعد البناء:
   ```bash
   npm install        # مرة واحدة
   npm run build      # → مجلد dist/ (انشره على أي استضافة)
   # أو للملف الواحد القابل للتوزيع مباشرة:
   npm run build:preview   # → preview-dist/index.html
   ```
3. انشر `dist/` على أي استضافة ثابتة (GitHub Pages / Netlify / Vercel)،
   أو وزّع `preview-dist/index.html` كما هو — يعمل دون خادم.

## الخطوة 8 — تسجيل الطلاب (دور المعلم)

**الطريقة الأسهل — من اللوحة:**
1. افتح **رابط لوحتك الخاص** (المحفوظ في المفضلة، الذي ينتهي بـ `?k=…`) —
   اللوحة تفتح مباشرة.
2. تبويب **Add student · إضافة طالب** ← اكتب اسم الطالب ← **Add**.
3. ستظهر لك بياناته: الاسم + **رمز الدخول** (مثل `K7M2QP`) ← أرسلها للطالب يدوياً
   (واتساب/بريد/ورقياً — كيفما تشاء).

**أو يدوياً في الجدول:** أضف صفاً في ورقة `Students`:
- `StudentName`: اسم الطالب (كما سيكتبه عند الدخول)
- `AccessCode`: رمز من اختيارك (حروف كبيرة/أرقام)
- اترك `StudentID` فارغاً — يُولَّد تلقائياً عند أول تسجيل دخول.
- لتعطيل حساب طالب لاحقاً: اجعل `AccountStatus` بقيمة `inactive`.

## الخطوة 9 — دخول الطالب

1. يفتح الطالب الموقع ← **لا يرى أي محتوى** — تظهر له صفحة تسجيل الدخول فقط
   (بوابة إجبارية: الاسم + الرمز اللذان أرسلتهما له).
2. يدخل **الاسم** (مطابقاً لما سجلته — لا يهم حالة الأحرف/المسافات الزائدة)
   و**رمز الدخول**.
3. بعد النجاح يدخل الموقع كاملاً، وتظهر شارة اسمه أعلى الصفحة، والشارة تتحول
   إلى **Synced · 已同步**، وأي تقدم سابق كان محفوظاً على جهازه **يُرحَّل
   تلقائياً مرة واحدة** إلى حسابه.
4. من شارة اسمه (أو تبويب **👤 My progress · 我的进度**) يفتح **صفحته الشخصية**
   `#/me`: إجمالي الدروس المكتملة ونسبة المقرر والكلمات المتقنة ووقت التعلم
   النشط وآخر نشاط + تفاصيل كل درس وأفضل نتائج الاختبارات + زر تسجيل الخروج.
5. عند الخروج (أو انتهاء الجلسة بعد 90 يوماً) تعود البوابة — لا تصفح دون حساب.
   وطوال أي انقطاع للإنترنت يتابع الطالب الدرس عادياً ويُحفَظ كل شيء في
   "صندوق صادر" ويُرسَل تلقائياً عند عودة الاتصال.

## تحديث نسخة منشورة سابقاً (مهم!)

إذا نشرت نسخة أقدم من الكود (مثلاً نسخة رمز المعلم)، فالتحديث لا يغيّر الرابط:

1. في محرر Apps Script: الصق محتوى `Code.gs` الجديد فوق القديم،
   و`Dashboard.html` الجديد فوق القديم (و`LessonsData.gs` إذا تغيّر).
2. **Deploy ← Manage deployments ← ✏️ (Edit) ← Version: New version ← Deploy**.
3. رابط `/exec` نفسه يستمر بالعمل للموقع وللوحة — لا تحدّث `src/config.ts`.
4. اختبر: افتح **رابط لوحتك الخاص** (`/exec?k=…`) ← تظهر اللوحة مباشرة.
   وافتح الرابط المجرّد `/exec` ← يجب أن تظهر صفحة "Nothing here" الفارغة.
   المفتاح لا يتغير عند إعادة النشر (محفوظ في Script Properties)، فإن ضاع
   شغّل `rotateDashKey` أو `setupSheets` واقرأ الرابط من سجل التنفيذ.

## المتابعة اليومية (لوحة المعلم)

- **Students · الطلاب**: لكل طالب — الدروس المكتملة /15، نسبة المقرر، الكلمات
  المتقنة، وقت التعلم النشط، آخر نشاط، وحالة (مكتمل/يتقدم/لم يبدأ/لا نشاط حديث).
  اضغط أي صف للتقرير الكامل.
- **تقرير الطالب**: حالة كل درس، أفضل نتائج الاختبارات، وآخر 100 حدث تعلم
  (فتح درس، تشغيل صوت، إتقان كلمة…).
- **Course · المقرر**: أي الدروس بدأها/أنهاها أكبر عدد من الطلاب + قائمة
  "لا نشاط منذ 14+ يوماً" (ملاحظة وصفية فقط — ليست حكماً على انتباه الطالب).

## بعد أي تعديل على الكود

1. حدّث الملفات في محرر Apps Script.
2. **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy**.
   (رابط `/exec` لا يتغير — لا حاجة لتحديث `src/config.ts`).

## أسئلة شائعة

- **هل رابط الطلاب سري؟** لا، ولا يجب أن يكون: الأمان في رمز كل طالب — كل عملية
  تتحقق من جلسة موقّعة، والطالب لا يرى إلا بياناته (التحقق في الخادم).
  أما **لوحة المعلم فتُفتح برابط خاص ينتهي بـ `?k=…`** لا يعرفه سواك — الرابط
  المجرّد يعرض صفحة فارغة، وعمليات المعلم محجوبة تقنياً عن واجهة الموقع
  العامة في كل الأحوال (مهم لأن رابط الطلاب منشور داخل كود الموقع).
- **وصل رابط اللوحة الخاص لشخص خاطئ؟** شغّل الدالة `rotateDashKey` في محرر
  Apps Script ← يصدر رابطاً جديداً فوراً ويبطل القديم (دون إعادة نشر).
  لإجبار كل الطلاب على إعادة الدخول: احذف صفوف ورقة `Sessions`.
- **طالب فقد رمزه؟** عدّل `AccessCode` في صفه بورقة `Students` وأرسل له الجديد.
  جلساته القديمة يمكن إلغاؤها بحذف صفوفه من `Sessions`.
- **هل يعمل دون إنترنت؟** نعم — التقدم يُخزَّن في "صندوق صادر" محلي ويُرسل
  تلقائياً عند عودة الاتصال دون فقدان (الشارة: Waiting to sync… ثم Synced).
- **الحدود المجانية لـ Apps Script** تكفي فصلاً دراسياً كاملاً بسهولة: الطلبات
  مجمَّعة (حدث واحد لكل دفعة)، والقراءة الواحدة تجلب كل بيانات الطالب مرة واحدة.
- **أريد تجربته دون نشر؟** المشروع يحتوي محاكاة كاملة للخلفية:
  `npm run test:remote` — 108 اختبارات تشمل طالبين ومعلماً ووضع الطيران وبوابة الدخول والصفحة الشخصية.
